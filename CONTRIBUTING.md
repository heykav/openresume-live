# Contributing to OpenResume Live

Thanks for helping improve this project.

## Responsibilities

- Preserve the deterministic, explainable design.
- Keep the app local-first and free from AI inference.
- Prefer evidence-based rule changes over opaque heuristics.
- Add or update tests when behavior changes.

## Workflow

1. Fork the repository and create a feature branch.
2. Install dependencies with `npm install`.
3. Run `npm run typecheck`, `npm run test`, and `npm run build` before opening a pull request.
4. Keep reporting and score changes explainable.
5. Update documentation when introducing new rules or scoring changes.

## Pull request expectations

- Include a concise description of the user-visible change.
- Link any issue or design note.
- Provide testing evidence and note any remaining limitations.

# Privacy

OpenResume Live is a static website. It has no account system, backend, analytics, or AI inference. Resume content is rendered and edited in your browser and is not transmitted to an OpenResume service.

## Local persistence

The current draft is saved in this browser's local storage so it can be restored after a reload. Browser storage is specific to this device and browser profile. Clearing site data removes the saved draft; use **Export draft** to download a JSON backup.

## Files and printing

PDF and DOCX resume files are parsed locally in your browser with bundled open-source libraries. Files are not uploaded or sent to a server. PDF import reads selectable text only, supports up to 20 pages, and is limited to files smaller than 10 MB. Scanned-image PDFs are not supported. The extracted text is shown for review before you replace the current draft.

**Save as PDF** uses the browser's print dialog. **Export draft** creates a JSON download locally.

## LinkedIn and resume score

You can save a LinkedIn profile URL as part of your draft. OpenResume does not authenticate with LinkedIn, request profile data, or scrape the site; it only renders a validated profile link.

The score is calculated in the browser from the resume fields using a fixed completeness checklist. It does not evaluate job fit, predict hiring outcomes, or claim to reproduce an applicant tracking system.

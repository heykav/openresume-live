# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Inferred from the MVP brief: people creating or updating a resume and portfolio for professional opportunities. The primary audience and their specific context are undecided.

## Product Purpose

OpenResume Live is a browser-based tool for editing resume content and seeing a portfolio-style presentation update live. Success for this MVP is that a user can edit their details, see the result immediately, and return to their work later.

## Positioning

The requested distinction is a resume editor paired with a live portfolio preview. This MVP must not use AI inference.

## Operating Context

Inferred: users work with personal career information in a web browser. The MVP should be usable without an account or server-side service.

## Capabilities and Constraints

Confirmed: resume editing, live preview, and no AI inference. The implementation is a static web app deployable to GitHub Pages. Persistence, export formats, and future collaboration are undecided.

## Evidence on Hand

No user-provided resume content, testimonials, or brand assets are available. Any initial resume content is illustrative sample data and must be easy to replace.

## Product Principles

- Keep editing and its visible result connected.
- Treat user-authored resume content as the source of truth.
- Make the initial experience useful without an account.
- Never imply AI-generated or verified content.
